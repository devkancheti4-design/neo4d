# ARC on neo4d's core

Generated by `neo4d/arc_experiment.py`. ARC-AGI (the original corpus: 400 training and 400 evaluation tasks). The same domain-free core as `results/CORE.md`; the ARC adapter (`neo4d/domains/arc.py`) supplies a small set of grid operations, programs of at most 3 steps, and a checker that runs a program on a task's training pairs. Every task is scored on its hidden test output, which no solver sees.
