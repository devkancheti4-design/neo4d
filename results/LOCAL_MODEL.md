# A local model with neo4d as its brain

Generated by `neo4d/local_model.py`. Local model: **phi4-mini** (ollama, on this machine). **176 bug-fix tasks** from 31 QuixBugs programs: each a correct program broken on one line by the mutation teacher, kept only if its own tests catch it, in one seeded stream. Fixed: every test passes again. neo4d's patterns are decided by the RELATE v2 law; the model reads and writes, neo4d and the tests decide.

| solver | **fixed** | the original line exactly | model calls | calls per task | test runs | time |
|---|---|---|---|---|---|---|
| model alone | **30.7%** (54) | 29.0% | 176 | 1.00 | 142 | 100s |
| model + tests | **42.0%** (74) | 38.1% | 407 | 2.31 | 324 | 189s |
| neo4d + model | **62.5%** (110) | 58.5% | 251 | 1.43 | 1809 | 250s |

The ceiling: a writer that always replies with the exact original line fixes **166 of 176** through this harness. The rest are bugs like `return x` -> `return None`, where the corrected line looks more like another line of the function and is placed there instead - every writer here loses those.

**What this does not show.** The bugs are injected by the mutation teacher, so the stream is rich in repeats - a closed domain, where memory helps most. A fix that passes the tests but differs from the original line is counted as fixed; the tests are the judge, as they are for every solver here.
