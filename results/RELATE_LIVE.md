# RELATE live - a swarm learning relations like neurons

Generated by `neo4d/relate_live.py`. A relation is a fix with the project-specific parts abstracted (`neo4d/relations.py`); a literal edit is the same with nothing abstracted. Every relation and every literal edit is a neuron whose strength the law sets on every event (0 unknown, 1 primed, 2 active - it proposes fixes, 3 proven). Exact generation of the real fixed line counts; candidates are what a repair would have to try. Each repair is scored before it is learned from.

**What this shows.** Across projects, relations generalise where literal edits do not transfer; inside one project's history, its own literal edits recur and memorising them wins. The same law over both - memory and generalisation, like episodic and semantic memory - beats the law over either alone on both streams, and its coverage keeps rising as it learns. The no-law rows reach more only by proposing many times the candidates (on click, every literal edit at first sight: 19.8% at 261 per fix line, against the law's 14.5% at 59).

**What this does not show.** Coverage is patch level: a neuron generating the real fixed line. A repair would still run the suite on every candidate and need the SHIP law. Candidates per unchanged line multiply by the lines a repair searches; fault localisation decides how many that is.
