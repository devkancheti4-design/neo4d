# Does it absorb the topology of a domain?

Generated by `neo4d/kit_topology.py`, the RELATE v2 law deciding. A domain's topology here is the graph of its transformations - tokens as nodes, each rewrite the domain allows as an edge - with its invariants: connected components (separate families of rewrites) and the first Betti number (independent cycles, E - V + C).

Junk edges between the domain's tokens, any seed, any k: **none**. Edges reaching other operators' tokens - not junk, the `return <value> -> return None` operator (RET), whose rewrite is abstract (any value becomes None) and so is left out of the true graph: `( -> NULL`, `FALSE -> NULL`, `TRUE -> NULL`, `{ -> NULL`.

The graph is language-free: the canonical tokens (`&&` and `and` are both AND, `!` and `not` both NOT) make the C domain's swap graph the same 70 edges, so a graph absorbed from Python is the C graph too - which is why the swap operators carried to C with no C lesson (`results/DOMAIN_HARD.md`, E2).

**What this shows.**
- In a closed domain it does absorb the topology, exactly: by 10,000 taught lines every true edge is recovered in every seed and the learned graph equals the true one - same edges, 7 components, Betti number 19 - from 10,000 lines on.
- On real bugs the learned graph is still growing at the end of the corpus: from the middle of the stream to its end its edges grow 1.59x. There is no settled topology to absorb yet at 706 fixes - the novelty measurement (`results/NOVELTY.md`) says how far the curve has to run.
- It is a graph of rewrites, learned from tests - not geometry in any metric sense, and not the 4D polytopes the swarm once ran on.
