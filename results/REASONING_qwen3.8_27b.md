# Reasoning tokens against neo4d's search

**Model `qwen3.8:27b-mtp-q4_K_M`. Where answers can be checked exactly, neo4d's model-free search matches or beats the reasoning model: 60/60 and 57/60 puzzles (Countdown, Blocks World; 2000 checks, depth limited only by the budget) against 58/60 and 54/60 for the model thinking - at zero model tokens against 776 and 4078 per problem.** Check it in a second on any computer: `python -m neo4d.reasoning_vs_search --recheck` (docs/REPRODUCE.md).

On two checkable puzzles, neo4d's search solved 51/60 (Countdown) and 49/60 (Blocks World) with no model tokens; the reasoning model, thinking, solved 58/60 and 54/60 with 776 and 4078 tokens per problem. The model's own instant guess adds nothing: guess + search solved 52/60 and 44/60 - on Blocks fewer than search from a fixed start, because a wrong guess leads the search astray. The search here is a plain beam search ranked by the checker's partial score: no law steers it.

What this does not show: these are small puzzles with an exact checker, where a search over one-step changes is strong; one model (qwen3.8:27b-mtp-q4_K_M) and one seed; and a domain without a cheap, exact checker gives the search nothing to rank by. The claim is: where an exact checker exists, neo4d's search replaces paying for reasoning tokens. Answers are read the same way in every configuration (the domain's parser, then \boxed{...}, LaTeX operators and inline expressions); the first run's stricter reading is kept in results/data/reasoning/REASONING_first_parse.md.

Generated by `neo4d/reasoning_vs_search.py`. Model `qwen3.8:27b-mtp-q4_K_M` (ollama, NVIDIA L4); 60 tasks per domain, seed 1; temperature 0.6, seed 0, one try. A: the model reasons (up to 16,000 tokens). B: reasoning off (ollama's think=false), an instant guess, then neo4d's search from it. B0: the guess alone. S: neo4d's search alone, no model.
